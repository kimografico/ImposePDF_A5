# Impositor A5 / ImposePDF_A5

Impositor A5 — herramienta para imponer PDFs A4 en booklets A5 lista para impresión dúplex (saddle-stitch / gusanillo).

Descripción corta:

- Español: Impositor A5 genera un PDF A4 apaisado con dos páginas A5 por cara, ordenadas para encuadernación en gusanillo.
- English: Saddle-stitch imposition of A4 PDFs into A5 booklets.

Contenido del repositorio:

- `main.py` — entry point
- `ui/` — interfaz PyQt6
- `core/` — lógica de imposición (testable)

Pruebas rápidas y empaquetado: ver [proceso.md](proceso.md).
